# /plan

1. @pm: problem, metrics and scope for new work; MoSCoW. @product-owner: stories + criteria.
2. @architect / @tech-lead: design impact, ADRs needed, contract changes.
3. @project-manager: breakdown, dependency graph, critical path, range estimates, risks.
4. @eng-manager: priorities, capacity<!-- codex --> (Claude/Codex)<!-- /codex -->, risk review.
5. @scrum-master: role debate → DEBATE-<epic>.md (agreements, disagreements, decisions needed).
6. PLAN CHECKPOINT: epics, tasks, architecture, stack, risks, open questions → owner approval.
   Write `docs/project-specs/PLAN-<name>.md`.
